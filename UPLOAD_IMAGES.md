## 🔄 Using Different Formats?

If you're using PNG or WebP instead of JPG:

1. Open `app/cantos/page.tsx`
2. Change `.jpg` to `.png` or `.webp` in the image paths
3. Example: `image: "/images/cantos/canto-1.png"`

## 🎯 Quick Test
